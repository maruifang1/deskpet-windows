# DeskPet for Windows

Windows 悬浮桌宠，复用 iOS 版生成的黑银 Q 版形象 PNG。窗口透明无边框、始终置顶、可拖拽，点按换表情，按时段和电池状态自动换帧，并内置孤独递进与连击彩蛋。

## 运行

```bash
npm install
npm start
npm test
```

## 操作

- 单击桌宠本体：随机开心 / 惊讶 / 犯困反应。
- 双击：害羞；生气状态下双击可安抚和解。
- 长按：犯困。
- 拖拽：拎起桌宠移动位置；快速甩出后桌宠会自己爬回原位。
- 连击彩蛋：2 秒内连点 3 次开心、5 次晕眩、8 次真生气；生气持续 30 秒或等待双击安抚。
- 下方按钮 ❤ / ! / ☾ / 💬：开心 / 惊讶 / 犯困 / 聊天，不参与连击计数。
- 右键桌宠：退出。

## 表情帧

- 时段 6-11 / 11-14 / 14-18 / 18-23 / 23-6 自动切换清晨/午间/下午/傍晚/深夜形象。
- 充电中显示充电帧，低电量显示担心帧。
- 互动帧：开心 / 惊讶 / 犯困 / 晕眩 / 生气 / 害羞 / 伸懒腰 / 委屈。
- 行为帧：左右张望 / 走路 A/B/C/D/E/F 六帧循环 / 跳舞。
- 眨眼效果用图片轻微缩放代替，不再切换眨眼帧。

## 孤独递进

长时间不互动时桌宠会依次进入：5 分钟张望 → 10 分钟闲逛+吹泡泡 → 15 分钟委屈 → 20 分钟伸懒腰 → 30 分钟睡着；任意互动立即唤醒并重置。

## 台词

每个时段/表情都有独立词池，互动台词不立即重复，闲时碎念按日期稳定轮换；充好电会触发跳舞彩蛋。

## 结构

- `main.js`：Electron 主进程（透明置顶窗口、拖拽边界钳制）
- `index.html` / `style.css`：桌宠界面与动画
- `pet-logic.js`：纯逻辑（时段/手势/连击/选句/孤独状态机）
- `pet.js`：DOM 与 Electron IPC 胶水
- `assets/`：PNG 表情帧
- `tools/raw/` + 处理脚本：新表情帧生成与抠图
- `test/`：`node --test` 单元测试

## 阶段拆分

**阶段 0（前置）：写完 README.md**
- 将计划中的全部新功能（手势/连击/孤独链/新帧/操作说明）写入 `deskpet-windows/README.md`，替换原有操作说明。完成后报告并进入阶段 1。

**阶段 1：点按修复 + 手势与连击系统**
- 抽出 `pet-logic.js` 纯逻辑模块（时段映射、手势分类、连击、生气状态），`pet.js` 只留 DOM/IPC 胶水；新增 `node --test` 测试。
- 点按修复：改用 `pointerdown/pointermove/pointerup`，按压状态同步写入，IPC 只作拖拽基准；气泡 `pointer-events: none`；`main.js` 窗口移动钳制边界。
- 手势：单击随机反应、双击害羞、长按犯困、拖拽移动、快速甩出后爬回原位、2 秒内 3/5/8 连击分别触发开心/晕眩/生气，生气保持到双击安抚或 30 秒消气。
- 新表情先用现有帧临时映射（怒→surprised、晕/羞→happy、伸懒腰/委屈→sleepy，走路/跳舞用 CSS、眨眼用图片缩放）。
- 验收：`npm test` 通过；`npm start` 确认点桌宠本体每次都反应，双击/长按/拖拽/甩出/3-5-8 连击/安抚全部生效；报告结果并询问是否同意进入阶段 2。

**阶段 2：台词扩容 + 孤独递进 idle**
- 现有 mood 各扩到 12-15 句、`chat` 20-25 句，新表情预配 8-12 句，另配场景台词；保持高冷吐槽+偶尔皮。
- 闲时碎念按 `dayOfYear` 稳定轮换，互动台词“不立即重复”随机。
- 孤独递进：5min 张望→10min 闲逛+吹泡泡→15min 委屈→20min 伸懒腰→30min 睡着；充好电跳舞彩蛋；以上暂用现有帧+ CSS。
- 验收：`npm test` 通过；手动确认台词多样化、孤独链按时出现、互动后重置。

**阶段 3：生成并接入 14 张新帧**
- 用 image-generation 技能以现有 `frame.morning.png` 绿幕帧为底图生成非走路帧，并一次生成一张 6 格走路序列图后拆分；14 张：晕眩/生气/害羞/伸懒腰/委屈/左右张望/走路 A-F/跳舞。
- 新增 Pillow 脚本：绿幕抠图、裁剪、高度 588 归一化、居中到 360x600 画布，写入 `deskpet-windows/assets/`；每张做非空/透明/尺寸校验，并展示给用户过目。
- 用真实帧替换阶段 1-2 的临时映射，接入图片缩放眨眼效果、走路循环、爬回、跳舞动画。
- 验收：全部新帧正常渲染、形象一致；完整手势与孤独链用真实帧重新验证。

**阶段 4：收尾与整体回归**
- 气泡按表情微调样式（生气红边、害羞淡粉等）；清理阶段 1-2 遗留的临时映射与临时代码。
- 验收：`npm test` 全绿；`npm start` 完整回归：点按/手势/连击/孤独链/按钮/右键退出/充电/时段换帧均正常；最终汇报变更清单。
