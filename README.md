# DeskPet for Windows

Windows 悬浮桌宠，复用 iOS 版生成的黑银 Q 版形象 PNG。窗口透明无边框、始终置顶、可拖拽，点按换表情，按时段和电池状态自动换帧，并内置孤独递进与连击彩蛋。

## 运行

```bash
npm install
npm start
npm test
```

## 操作

- 单击桌宠本体：随机开心 / 惊讶 / 犯困反应。
- 双击：害羞；生气状态下双击可安抚和解。
- 长按：犯困。
- 拖拽：拎起桌宠移动位置；快速甩出后桌宠会自己爬回原位。
- 连击彩蛋：2 秒内连点 3 次开心、5 次晕眩、8 次真生气；生气持续 30 秒或等待双击安抚。
- 下方按钮 ❤ / ! / ☾ / 💬：开心 / 惊讶 / 犯困 / 聊天，不参与连击计数。
- 右键桌宠：退出。
- 系统托盘：右键托盘图标 → “退出桌宠”即可关闭程序。
- 前台窗口感知：切换写代码 / 看视频 / 开会 / 打游戏 / 刷网页窗口时，桌宠会暖句提醒；同一分类 15 分钟内不重复打扰。
- 天气感知：下雨 / 下雪 / 风暴等天气变化时提示带伞、加衣；早晨 7-10 点遇到雨雪风暴天气每天提醒一次。
- 久坐提醒：连续处于工作或娱乐类窗口 45 分钟后，桌宠会提醒喝水、起身活动。
- 点击部位差异：单点头部 = 害羞（摸头），单点身体 = 惊讶（戳身），单点脚下 = 开心（挠脚）。
- 节日/纪念日倒数：元旦、春节、清明、端午、中秋、国庆以及 7/3、8/12 纪念日当天有专属台词，节日前 3 天每天提示一次“还有 N 天”。
- 粒子特效：开心/跳舞时飘爱心；雨雪天气持续飘雨/飘雪，深夜有星点闪烁。
- 视觉氛围：脚底阴影随呼吸缩放，形象按清晨/午间/下午/傍晚/深夜/充电/低电量带不同柔光。
- 贴边散步：空闲时每隔 12-20 分钟沿屏幕边缘溜达一小段再回到原位，配走路帧和“溜达一圈”台词。
- 摸鱼/游戏彩蛋：全屏视频或全屏游戏窗口出现时，桌宠会切换成“帮你望风 / 带我一个”的整活台词。

## 表情帧

- 时段 6-11 / 11-14 / 14-18 / 18-23 / 23-6 自动切换清晨/午间/下午/傍晚/深夜形象。
- 充电中显示充电帧，低电量显示担心帧。
- 互动帧：开心 / 惊讶 / 犯困 / 晕眩 / 生气 / 害羞 / 伸懒腰 / 委屈。
- 行为帧：左右张望 / 走路 A/B/C/D/E/F 六帧循环 / 跳舞。
- 眨眼效果用图片轻微缩放代替，不再切换眨眼帧。

## 孤独递进

长时间不互动时桌宠会依次进入：5 分钟张望 → 10 分钟闲逛+吹泡泡 → 15 分钟委屈 → 20 分钟伸懒腰 → 30 分钟睡着；任意互动立即唤醒并重置。

## 台词

每个时段/表情都有独立词池，互动台词不立即重复，闲时碎念按日期稳定轮换；充好电会触发跳舞彩蛋。

### 隐私与网络

- 前台窗口感知只读取当前窗口的进程名与标题，不上传、不落盘。
- 天气通过 wttr.in 免密钥接口获取，默认按 IP 自动定位；断网或接口失败时静默降级，不影响桌宠本体。

## 结构

- `main.js`：Electron 主进程（透明置顶窗口、拖拽边界钳制、托盘、窗口/天气感知）
- `index.html` / `style.css`：桌宠界面与动画
- `pet-logic.js`：纯逻辑（时段/手势/连击/选句/孤独状态机/感知分类）
- `pet.js`：DOM 与 Electron IPC 胶水
- `preload.js`：contextBridge 暴露 IPC
- `assets/`：PNG 表情帧
- `tools/window-info.ps1`：前台窗口信息采集（PowerShell）
- `tools/raw/` + 处理脚本：新表情帧生成与抠图
- `test/`：`node --test` 单元测试
